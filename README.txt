# GeoFixers Backend Render Deployment

This package includes:
- `render.yaml` — Deployment configuration for Render.
- `requirements.txt` — Python dependencies.
- `frontend_test.js` — Example frontend script to test the API.

## Steps to Deploy
1. Push your backend code + these files to GitHub.
2. Create a new **Web Service** on Render.
3. Set environment variables (`SUPABASE_URL`, `SUPABASE_KEY`, etc.).
4. Deploy and test at `https://<your-service>.onrender.com/docs`.
